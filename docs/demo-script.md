# Сценарий демонстрации на 3–5 минут

1. **Проблема (30 секунд).** Бухгалтер получает неожиданную смену реквизитов. Продукт не заменяет шлюз и не подтверждает отправителя; он помогает заметить признаки в тексте.
2. **Мошенническое письмо (60 секунд).** Нажать «Новые реквизиты». Показать высокий уровень, сочетание срочности/платежа/запрета звонка и реальные цитаты.
3. **Действия (30 секунд).** Подчеркнуть рекомендацию звонить по ранее известному номеру, а не отвечать на письмо.
4. **Обычное письмо (40 секунд).** Выбрать «Обычное письмо». Обратить внимание на формулировку «явных признаков не обнаружено», а не «безопасно».
5. **Сложный случай (50 секунд).** Вставить «Не переводите деньги, пока не проверите реквизиты». Показать обработку отрицания; затем упомянуть false negative из evaluation.
6. **Режимы и ограничения (40 секунд).** Rules работает без ключа. AI опционален, отправляет текст провайдеру и при сбое честно возвращается к правилам. Завершить метриками 12 TP, 10 TN, 0 FP, 0 FN на маленьком синтетическом наборе — и сразу уточнить, что 100% на нём не означает производственную точность.
