# генИИ — анализатор подозрительных писем

Учебный MVP команды KIB-22 НИУ ВШЭ для бухгалтеров и офис-менеджеров малого и среднего бизнеса. Пользователь вставляет текст письма и получает объяснимые признаки риска, точные цитаты и безопасные следующие действия.

## Возможности

- 9 категорий правил: срочность, реквизиты, перевод, секреты доступа, запрет проверки, авторитет, ссылки, сторонние ресурсы и психологическое давление.
- 4 уровня результата без ложной «вероятности мошенничества».
- 4 мгновенных учебных примера и лимит 12 000 символов.
- Автономный rules-режим без сети и ключа.
- Опциональный OpenAI-compatible AI через сервер с Zod, тайм-аутом, проверкой цитат и fallback.
- 30 синтетических оценочных писем, unit/API-level и Playwright E2E тесты.
- Русский адаптивный интерфейс с keyboard/focus и aria-состояниями.

Приложение не читает почту, не открывает ссылки или вложения, не хранит текст и не подтверждает подлинность отправителя.

## Стек и требования

Next.js 16 App Router, React 19, TypeScript strict, CSS Modules, Zod, Vitest и Playwright. Требуются Node.js 20.9+ и npm 10+.

## Установка

```bash
git clone https://github.com/F5re/hse_major_hw1.git
cd hse_major_hw1
npm ci
npm run dev
```

Открыть `http://localhost:3000`. После установки запуск выполняется одной командой `npm run dev`.

## Режимы анализа

Rules работает без `.env.local`. Для AI скопируйте `.env.example` и задайте серверные значения:

```dotenv
AI_API_KEY=...
AI_BASE_URL=https://provider.example/v1
AI_MODEL=<реальное имя модели провайдера>
AI_TIMEOUT_MS=12000
AI_ACCESS_TOKEN=<необязательная защита demo-режима>
```

Не добавляйте `NEXT_PUBLIC_`: ключ не должен попасть в браузер. Перед включением UI предупреждает, что письмо передаётся выбранному внешнему провайдеру. При отсутствии ключа, тайм-ауте, HTTP/JSON/schema-ошибке результат правил остаётся доступен и не выдаётся за AI.

```bash
npm run build
npm run test:e2e
```

На 22 однозначных письмах: TP 12, TN 10, FP 0, FN 0, precision/recall/F1 1,000. Восемь неоднозначных примеров исключены из бинарной метрики. Полученные 100% относятся только к маленькой синтетической выборке, составленной авторами правил, и не являются производственной точностью. Подробности: [оценка](docs/evaluation.md).

## Ограничения

Анализируется только текст. Не видны From/Reply-To, SPF/DKIM/DMARC, настоящий адрес ссылки, вложения, изображения и история переписки. Правила имеют ложные срабатывания и пропуски; AI тоже ошибается и создаёт отдельный риск конфиденциальности. Любой платёж или передача доступа требует независимой проверки.
