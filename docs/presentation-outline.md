# План презентации: 5 слайдов

## 1. BEC: проблема рабочего решения

Бухгалтеру нужно решить, выполнять ли неожиданную инструкцию. FBI относит BEC к наиболее финансово разрушительным интернет-преступлениям. Типовые сценарии: смена реквизитов, срочный перевод, код доступа.

## 2. Аналоги и узкая ниша

Microsoft Defender, Proofpoint и Cloudflare работают в почтовой инфраструктуре. «генИИ» — учебный помощник для МСБ: вставленный текст, понятные причины, конкретное действие, автономные правила.

## 3. Архитектура и безопасность

React UI → Next.js Route Handler → rules; опционально один ограниченный AI-вызов. Zod, server-only key, лимиты, no-store, проверка цитат, prompt injection как данные.

## 4. Демонстрация

Смена реквизитов → высокий риск → цитаты → звонок по известному номеру. Затем обычное письмо и честное ограничение вывода.

## 5. Результаты и развитие

30 синтетических писем; TP 12, TN 10, FP 0, FN 0, F1 1,000 на 22 однозначных. 100% относится только к составленной авторами маленькой выборке. Далее: независимая разметка, распределённый rate limit, корпоративная политика AI-провайдера.
