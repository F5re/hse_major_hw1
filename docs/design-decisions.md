# Дизайн-направление

## Концепция

Интерфейс напоминает рабочий лист внутренней проверки, а не рекламный AI-сервис. Главный визуальный приём — спокойная вертикальная полоса статуса результата; остальная композиция нейтральна. Это помогает бухгалтеру быстро перейти от текста письма к следующему безопасному действию.

## Токены цвета

| Роль | Значение | Назначение |
| --- | --- | --- |
| Фон | `#f4f7f6` | Холодный нейтральный фон |
| Поверхность | `#ffffff` | Рабочие области |
| Текст | `#172321` | Основной графитовый текст |
| Вторичный текст | `#53615e` | Пояснения |
| Акцент | `#08675d` | Кнопки, фокус, идентичность |
| Граница | `#cfd9d6` | Разделение без теней |
| Высокий риск | `#a12b2b` | Только критический статус |
| Умеренный риск | `#9a5b00` | Предупреждение |
| Низкий риск | `#19704b` | Отсутствие явных признаков, не «безопасно» |

## Типографика

Системный стек `Inter, Arial, sans-serif` с гарантированной поддержкой кириллицы и без внешних запросов. Один шрифт снижает визуальный шум. Основной текст 16 px, пояснения 14 px, заголовок страницы 30–36 px, межстрочный интервал 1.5–1.6. Строка текста ограничена примерно 75 знаками.

## Отступы

Базовый шаг — 4 px. Рабочие значения: 8, 12, 16, 24, 32 и 48 px. Радиусы 4–10 px используются по иерархии, а не одинаково у каждого блока.

## Макет и wireframe

```text
┌ генИИ ────────────────────────────── Команда KIB-22 ┐
│ Проверка подозрительного письма                     │
│ Короткое объяснение и ограничение метода            │
├────────────────────────┬────────────────────────────┤
│ Письмо                 │ Результат / пустое состояние│
│ [текстовое поле       ]│ Статус                      │
│ [                    ] │ Причины и точные цитаты     │
│ Примеры                 │ Что делать                  │
│ [Проверить] [Очистить]  │ Ограничения                 │
├────────────────────────┴────────────────────────────┤
│ Метод проверяет только вставленный текст · о проекте│
└─────────────────────────────────────────────────────┘
```

На ширине от 900 px — две неравные колонки 48/52. На мобильном — одна колонка: ввод, действия, результат, ограничения. Всё выровнено по левому краю.

## Почему это подходит аудитории

Бухгалтеру или офис-менеджеру важны основание решения и следующее действие, а не технический балл. Поэтому результат начинается со словесного статуса, затем показывает цитату и короткую инструкцию. Примеры встроены рядом с вводом для быстрой демонстрации.

## Что намеренно исключено

Нет градиентов, свечения, стеклянных панелей, роботов, hero-баннера, декоративных графиков, статистики без данных, случайных анимаций, эмодзи, отзывов и обещаний точности. После самопроверки убрана идея сетки одинаковых карточек: причины оформлены как последовательный список проверки.
